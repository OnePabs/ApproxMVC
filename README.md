# ApproxMVC
Algorithms to find an approximate minimum vertex cover of a graph.


Building the Program
    ApproxMVC/src
    run make on the terminal. The executable is called approxmvc and is in ApproxMVC/src

Running the program
    In the terminal cd to ApproxMVC/src
    Option 1: ./approxmvc
        Command Line interface will prompt you for the algorithm and edges file
    Option 2: ./approxmvc algorithm_name edges_filepath
        No other actions required.
